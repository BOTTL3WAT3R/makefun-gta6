**Golden Hour — Costa Vera.** An original 3D open-world crime game that plays offline in a desktop browser from static files. Explore a sun-soaked coastal city on foot and by car: steal and drive six kinds of vehicles in live traffic, dodge or fight the Policía del Sol through a five-star wanted system with patrol cars, five-star roadblocks and a spotlight helicopter, and climb from errand runner to kingpin through seven story jobs for fixer Pilar Duarte — steal the gold Tormenta from Hotel Palma, run the collection round against the clock, extract a hot accountant, wreck El Pulpo's ride, deliver the crown case at golden hour, then ride shotgun for Pilar herself against Capitán Vega's harbour patrol in the last tide. Side hustle included: taxi fares, the eight-gate Boardwalk Run, the ten-gate Gran Vuelta city tour, fifteen hidden packages, and shops for healing, armor and repairs. Full HUD with a live minimap, four synthesized radio stations, engine, siren and rotor audio, and localStorage saves. Built with three.js (vendored) and procedural everything — no downloaded assets.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome

# hand it in (writes out/ with the game, screenshots and dossier.json):
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
